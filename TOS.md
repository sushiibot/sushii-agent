## What the Service does

sushii-agent is an AI assistant for Discord servers. Server admins configure it, restrict
it to specific roles, and enable it in specific channels. When invoked, it reads relevant
message content, generates a response using a third-party LLM provider (OpenRouter), and
may take actions in the server through tools it has been granted — for example looking up
member or message history, or applying moderation actions like timeouts. See our
[Privacy Policy](./PRIVACY.md) for what data this involves and how it's handled.
