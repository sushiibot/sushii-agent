# TASKS.md

Open work, loaded into every main session (capped at ~3000 chars). Keep it an index: detail goes in
`tasks/<slug>.md`. Bump `updated:` whenever you touch an entry.

- Quick item: `- [ ] <title> — <one-line note> (id: t-<short>) size:quick created:YYYY-MM-DD updated:YYYY-MM-DD [links: repo/PR, run:<runId>]`
  - `[ ]` open, `[x]` done, `[-]` dropped (add a one-line reason).
  - `size:quick`: a one-off, done within hours or a day. Multi-day work is a project instead.
- Project: `- <name> — <status / next step> (updated:YYYY-MM-DD) → tasks/<slug>.md`
