# Durable knowledge catalog

This catalog maps durable topic notes. The workspace loads it into each chat session, with a 4000-character cap.
Topic bodies stay on disk. Paths are relative to the workspace home.

## Entries

Use one line per topic:
`- [Topic](memory/topics/<slug>.md) — Description. Read when: <task or question>.`

Add entries only for existing documents. Keep descriptions short and specific.
If a document moves or its scope changes, update its entry.
Do not list daily logs, task files, or repository source files here.
